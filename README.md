# Rabiatul's Personal Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — layout, typography, colors, and responsive styling
- `script.js` — mobile navigation and dynamic footer year

## Run locally
1. Download or extract the project folder.
2. Open `index.html` in a web browser.

For the smoothest development workflow, open the folder in Visual Studio Code and use the Live Server extension.

## Before publishing
Update the following placeholders in `index.html`:
- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/` with your actual LinkedIn profile URL
- `https://github.com/` with your actual GitHub profile URL

Review the skills list so it only includes technologies you can discuss confidently. Add repository links and screenshots only when projects are ready to share. Do not publish private FYP audio recordings or transcripts without appropriate permission.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `athirah-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In repository Settings, open Pages.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site and open the URL it provides.
